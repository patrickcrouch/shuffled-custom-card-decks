# 🂡🂡 Create Shuffled Card Decks for Memory Training 🂡🂡

Shuffled Custom Card Decks is a lightweight web application designed to enhance method of location/journey memory training through customizable card decks. Users can create shuffled, personalized decks to practice with, making it an ideal tool for memorization exercises. Built with simplicity in mind, the app offers an intuitive interface for seamless deck management and randomization, perfect for anyone looking to sharpen their memory skills.  No frameworks, no server, and uses local storage for the card decks.  This app was vibecoded mostly using Claude, but with occasional help from other AIs.
